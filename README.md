# Ex05 - Book Back Cover Page

## AIM
To design a book back cover page using HTML and CSS.

## DESIGN STEPS

### Step 01:
Create a Django project and app. Add the app to settings.py

### Step 02:
Create a folder `static` inside myapp and create `backcover.html` file.

### Step 03:
Design the back cover with:
- Book Title
- Author Name
- About the Book / Description
- Review / Quote
- Price and Barcode area
- Attractive background color and styling using CSS

### Step 04:
Run the server using `python manage.py runserver` and check the output.

### Step 05:
Push the code to GitHub.

## PROGRAM
File: `myapp/static/backcover.html`

## OUTPUT
Book back cover page is displayed successfully.

## RESULT
Thus the book back cover page is designed and executed successfully.
